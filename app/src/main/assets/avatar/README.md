# Avatar image slots

Drop a drawn avatar here to replace the vector art for one theme and rank.

- Name: `<theme>_<rank>.webp`, lower case — `system_e.webp` … `system_s.webp`, `neon_e.webp` … `neon_s.webp`.
- Size: 480×576 px (5:6), transparent background, WebP.
- Missing or unreadable files fall back to the vector avatar.
