# Avatar image slots

Drop a drawn avatar here to replace the vector art for one theme, hero and rank.

- Name: `<theme>_<hero>_<rank>.webp`, lower case — theme `system`/`neon`, hero `boy`/`girl`, rank `e`…`s`
  (for example `system_girl_c.webp`, `neon_boy_s.webp`).
- Size: 480×576 px (5:6), transparent background, WebP.
- Missing or unreadable files fall back to the vector avatar.
